I

How any of them start

the same four steps

  1. 01You send a note

    What you have, what is wrong, what it should do. A paragraph is enough to start.

  2. 02I answer honestly

    Including when I am not the right fit, which is a real answer and not a soft no.

  3. 03A written plan

    Scope and order in writing, so what you are buying is legible before you buy it.

  4. 04Work, in the open

    Something to look at every few days, and documentation left behind at the end.

Send a note
